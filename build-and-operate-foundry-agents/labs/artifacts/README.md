# Generated lab checkpoints

Drivers write their checkpoints, transcripts, evaluation reports and local session state here. These are
execution and recovery artifacts; their existence alone does not show that an outcome passed. Reusable
intelligence lives in reviewed, maintained source assets, not in unreviewed generated history.
Run earlier labs or `python catch_up.py --through N` from `labs/` to regenerate the required
checkpoints. Do not commit generated outputs or credentials.
